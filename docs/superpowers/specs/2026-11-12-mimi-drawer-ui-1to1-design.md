## 3. 范围

### 3.1 做

- `SideDrawerMenuView`：遮罩、面板宽度/圆角/背景、资料行、月打卡卡、更多功能、快捷记账、底部列表行。
- `MimiTheme`：补齐抽屉用到的间距、圆角、字号、Pro/VIP 色、面板宽度常量（少写魔法数）。
- 宫格图标：emoji → 灰线描（SF Symbol 或极简 Canvas）；风格对齐 D0。
- 交互：点遮罩关闭；资料/`>`/设置 → `.settings`；整张月卡 → `.calendar`；7+3 宫格现有 destination 不变；「填问卷」占位（关抽屉即可，不接外链）。

### 3.2 不做

- 图表统计、资产管理、账本、预算、小组件、分类、标签、导入导出、自动/定时记账、设置页 **本体** 的视觉精修（仅保证入口可点通）。
- 「填问卷参与共建」真实 Web/问卷链路。
- 用户相册头像同步（可用占位圆图 / emoji / 首字；不强制照片）。
- 从截图裁切真实 PNG 图标。
- 改 AI/识账/store 模型、根容器开合手势大改、版本发版流程。
- 强制把抽屉拆成多文件（失控时再局部抽 private View）。

## 4. 页面结构（就地精修，不整页拆文件）

仍在 `SideDrawerMenuView` 内按区块维护：

1. **遮罩 + 面板** — 点遮罩 `onClose`；面板宽约屏宽 82%（或等价 pt）；左缘贴边、右侧圆角；背景 `MimiTheme.background`。
2. **资料行** — 圆头像 · `store.userNickname` · **Pro** 蓝胶囊 + **VIP** 金标 · 右侧 `>`；整行或 `>` → `.settings`（去掉顶栏独立齿轮按钮）。
3. **月打卡卡** — 标题「November 2026」（展示月与现数据源一致即可）· **无** 星期头、**无** 收入多/支出多图例、**无** 卡内「全部记录 ›」· 日格热力 + 今日浅蓝底「今」· 底栏三列：记录天数 / 总记录 / 连续天数 · **整卡** → `.calendar`。
4. **更多功能** — 小节标题 + **3 列** LazyVGrid：图表统计、资产管理、账本管理、预算管理、小组件、分类管理、标签管理。
5. **快捷记账** — 小节标题 + 3 格：导入导出、自动记账、定时记账。
6. **底部列表** — 「设置」行 → `.settings`；「填问卷参与共建」行 → 占位（关抽屉）。

数据仍只读 `MimiStore` + 现有 `monthDayCells` / `recordedDaysCount` / `totalRecordsCount` / `streakDaysCount`。`DrawerDestination` 枚举值保持不变；问卷不新增 destination（或仅内部占位，不进路由表）。

## 5. 视觉 token 策略

- 背景与首页一致：`#F5F6FA` 级；卡片白；圆角约 18。
- 对照 D0 校准：面板宽度比例、资料行头像尺寸、Pro/VIP 徽章样式、热力格尺寸与「今」、3 列宫格图标底（浅灰圆角方）、标题 13 semibold 次要色、格子标题 12、统计数字约 19 bold。
- 热力色阶可沿用现实现蓝/橙浅阶；布局以 D0 为准（稀疏日号、今日「今」）。
- **硬标准**：层级、文案、3 列、底部队列、Pro/VIP、无图例/无卡内「全部记录」。
- **软标准**：线描图标「同风格近似」；头像占位可接受。

## 6. 交互与错误反馈

| 交互 | 期望 |
|---|---|
| 点遮罩 | `onClose` |
| 资料行 / `>` | `onSelectDestination(.settings)`（根容器关抽屉后进设置，行为与现逻辑一致） |
| 整张月打卡卡 | `onSelectDestination(.calendar)` |
| 更多功能 7 项 | 现有 destination 映射不变 |
| 快捷记账 3 项 | 现有 destination 映射不变 |
| 设置行 | `.settings` |
| 填问卷参与共建 | 占位：调用 `onClose`（或等价）；不接外链 |
| 开合动画 / 边缘手势 | 保持 `MimiRootContainerView` 现行为；本阶段不重做 |

空数据热力：空白日浅灰格即可；计数为 0 时仍显示数字。

## 7. 测试与验收

1. `verify-swift-project.mjs`：断言抽屉关键文案存在（至少含 `记录天数`、`总记录`、`连续天数`、`更多功能`、`快捷记账`、`图表统计`、`填问卷参与共建`、`Pro`、`VIP`），并确认无卡内依赖「全部记录 ›」作为抽屉热力标题链（整卡进日历即可）。
2. 不测像素；单测若有 store 计数则保持现有。
3. 真机/截图并排 **D0**：布局层级、3 列宫格、底部队列、Pro/VIP 无明显违和；各 destination 仍可点通。

**完成定义**：并排看 D0，布局/色/间距无明显违和；上表交互均可走通；图标风格接近即可。

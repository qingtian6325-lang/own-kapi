## 1. 意图

在现有原生 SwiftUI 工程上，把 **首页「记录」** 做到与原版 Mimi Money（参考截图）视觉与交互高度一致。业务逻辑（Groq 识账、问账、store）本阶段不改；只改 UI 层与首页相关贴纸。

## 3. 范围

### 3.1 做

- `HomeRecordView`：顶栏、月预算卡、分类预算展开/收起、净资产折叠、记录明细日卡、问我栏与 ＋/✕ 快捷面板。
- `AIAttachmentPanelView`：按图 B 微调三入口样式（相册 / 拍照 / 导入导出）。
- `MimiTheme`：补齐首页用到的间距、圆角、字号、阴影、色值常量（少写魔法数）。
- `MimiStickerIconView`：重绘**首页出现的**贴纸（流水分类图标、问我猫标、预算卡小图标等）；风格对齐 A/C，接受 Canvas 近似。
- 交互：金额眼睛显隐、点流水进详情（现有回调）、左滑删除 +「删除成功」toast、问我打开 AI Sheet、顶栏现有导航回调保持行为并校正视觉。

### 3.2 不做（本阶段）

- 侧栏抽屉、统计、全部记录日历、资产/预算管理页、分类方案管理、手动记账 Sheet、AI 对话 Sheet、账单详情 Sheet 的视觉精修。
- 从截图裁切真实 PNG 图标资源。
- 改 AI/识账/问账业务逻辑、持久化模型、版本发版流程（除非实现计划另列极小配套）。

## 4. 页面结构（就地精修，不整页拆文件）

仍在 `HomeRecordView` 内按 MARK 区块维护：

1. **顶栏** — 汉堡 · `记录▾` · 搜索 · `Main Ledger▾`（月胶囊若与 A 不一致则按 A 调整可见性/样式）
2. **月预算卡** — 月预算剩余 + 眼、进度条%、今日可用环、分类预算「共 N 项 / 展开」
3. **净资产行** — 净资产 + 30 天趋势 sparkline，可折叠
4. **记录明细** — 按日白卡片；行：贴纸 + 标题/备注 + 时间·账户胶囊 + 蓝支/橙收金额
5. **问我栏** — 猫标 +「任何事情都能问我」+ 右侧 ＋/✕
6. **快捷附件面板** — 展开后三入口（对照 B）；收起态对照 A

数据仍只读 `MimiStore` + `DynamicBudgetEngine`。硬编码演示月份若妨碍对照 A，改为与 store/当前月展示一致（仅展示层）。

## 5. 视觉 token 策略

- 背景 `#F5F6FA`、卡片白、支出蓝 `#2D5AF0`、收入橙 `#E8832E`、结余绿 `#36B37E`（与现有 `MimiTheme` 对齐并补齐缺失的 radius / spacing / typography / shadow）。
- 对照 A 校准：大标题字号、进度条高度与百分比徽章、今日可用环尺寸、卡片圆角与阴影、流水行间距与胶囊样式。
- **硬标准**：布局层级、颜色、间距、文案位置。  
- **软标准**：Canvas 贴纸「同风格近似」，不追求与原版位图像素级一致。

## 6. 交互与错误反馈

| 交互 | 期望 |
|---|---|
| 分类预算展开/收起 | 与 A 展开态文案/列表样式一致（展开态可参照现有实现 + A 细节） |
| 净资产折叠 | 趋势图显隐流畅 |
| 金额眼睛 | 切换 `RM****` / 真实金额 |
| 点流水行 | `onSelectTransaction` → 详情（不重做详情 UI） |
| 左滑删除 | 红圆垃圾桶；成功后中央「删除成功」toast（对照 D） |
| 点问我文案/猫标 | `onOpenRecordSheet(true)` |
| ＋ / ✕ | 展开/收起快捷面板（对照 B） |
| 顶栏动作 | 抽屉 / 切统计 / 日历·搜索 / 账本 sheet — 行为保持，视觉跟 A |

删除失败或空列表：保持现有 store 行为；空态文案若 A 未覆盖则不强行改。

## 7. 测试与验收

1. `verify-swift-project.mjs`：断言首页关键文案（如「月预算剩余」「任何事情都能问我」「删除成功」）与 theme token 存在。
2. 单测（能跑则跑）：金额格式、删除后条数；**不测像素**。
3. 真机/截图并排：静态对照 **A**；问我展开对照 **B**；删除对照 **D**。

**完成定义**：并排看 A，布局/色/间距无明显违和；上表交互均可走通；贴纸风格接近即可。

## 8. 风险

- Canvas 贴纸无法 100% 复刻手绘位图 → 已接受近似。
- `HomeRecordView` 文件偏大 → 本阶段不强制拆文件；某块改到失控时再局部抽 private View。
- 参考图批次曾出现错标 → 以本文 §2 文件名为准，不以旧 companion 标签为准。
